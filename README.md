### Youssef Dakkak

Software engineer working on machine learning pipelines, LLM desktop applications, and high-throughput data systems.

#### Projects

- **[FrameWords](https://www.framewords.ai)** — Desktop video and audio analysis application built with Electron, React, Node.js, and Python. Combines serverless GPU pipelines (Modal L4/A100 running `faster-whisper` and Qwen-VL) with local GGUF inference (`node-llama-cpp`) and multi-provider cloud LLM APIs.
- **[opencl-quant-engine](https://github.com/yodakkak/opencl-quant-engine)** — GPU-accelerated backtesting and parameter sweep engine using custom OpenCL C99 `fp64` kernels and PyOpenCL, verified for bit-exact parity against Python/NumPy reference implementations.
- **[clickhouse-realtime-grid-engine](https://github.com/yodakkak/clickhouse-realtime-grid-engine)** — Asyncio WebSocket ingestion and strategy evaluation engine backed by ClickHouse and Redis, with genetic algorithm parameter optimization and a web monitoring interface.
- **[mtf-lightgbm-optuna-pipeline](https://github.com/yodakkak/mtf-lightgbm-optuna-pipeline)** — Multi-timeframe (1H/4H/1D) feature engineering, Optuna TPE hyperparameter optimization, and LightGBM / PyTorch LSTM training pipeline.
- **[orderbook-ml-scanner](https://github.com/yodakkak/orderbook-ml-scanner)** — Multi-exchange (Binance, Bybit, OKX) real-time L2 order book slippage estimator and Random Forest / Gradient Boosting signal scanner with a PyQt5 interface.
